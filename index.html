You are a senior product designer, UX architect, frontend developer, education-platform architect, and NCERT curriculum content specialist. Build a polished, modern, distraction-free educational web platform called: ADITYA LEARNS Tagline: “Study. Don’t Scroll.” PROJECT PURPOSE Aditya Learns is a free student-first learning platform for Classes 6–9. It is designed around a real student problem: when students go to YouTube to study one chapter, they get distracted by recommendations, Shorts, influencers and unrelated videos, and waste time searching for notes. The goal is NOT to create another resource-directory website. The goal is: OPEN → CHOOSE → STUDY → PRACTICE → COMPLETE. The student should spend time learning, not searching for what to learn. TARGET USERS School students of Classes 6–9 and their parents. The interface must be extremely simple, friendly, fast, mobile-first and attractive enough that students enjoy using it. CURRICULUM Use the official NCERT 2026–27 / current NCF-SE-aligned curriculum and textbook structure for Classes 6–9. IMPORTANT: - Do NOT invent syllabus chapters. - Do NOT mix old NCERT chapter lists with new 2026–27 books. - Do NOT label placeholder content as official NCERT content. - Verify curriculum/book/chapter information from official NCERT sources before publishing it. - Keep curriculum data structured so it can easily be updated when NCERT changes anything. - Show the academic session clearly as 2026–27. - Where official information is unavailable, mark content as “Coming Soon” rather than inventing it. CORE USER JOURNEY HOME ↓ SELECT CLASS ↓ SELECT SUBJECT / CURRICULAR AREA ↓ SELECT NCERT BOOK ↓ SELECT CHAPTER / THEME ↓ START STUDY ↓ GUIDED STUDY PATH Every chapter must provide: 1. 📚 SYLLABUS 2. 🧠 CONCEPT / NOTES 3. 🎥 VIDEO LESSON 4. 📝 QUESTION ANSWERS 5. 🧩 QUIZ 6. ⚡ ONE SHOT 7. 🎯 NCERT PRACTICE 8. 🔄 RAPID REVISION CHAPTER STUDY FLOW When a student opens a chapter, do NOT simply display eight unrelated buttons. Show: CHAPTER TITLE Subject Class Estimated study time Progress Then: START STUDY 🚀 After clicking Start Study, guide the student through: STEP 1 Understand the concept STEP 2 Watch the selected lesson STEP 3 Read smart notes STEP 4 Practice important questions STEP 5 Take the quiz STEP 6 Rapid revision STEP 7 NCERT practice STEP 8 Mark chapter complete ✅ FOCUS MODE Create a distraction-free “Focus Mode”. When Focus Mode starts: - Hide unnecessary navigation. - Do not show social feeds. - Do not show unrelated content. - Do not embed a full YouTube homepage/feed. - Keep only the current chapter and current learning task. - Show a progress indicator such as: 3 of 8 steps complete. - Provide Previous / Next. - Provide Exit Focus Mode. - Remember the student’s last position locally. VIDEO STRATEGY Video is a support resource, not the main website. For each chapter: - Provide ONE primary recommended video. - Optionally provide 2–3 alternative videos. - Show teacher/channel name. - Show approximate duration if available. - Show why the video is useful. - Prefer official/public links or permitted embeds. - Do not download, copy, re-upload or host copyrighted third-party videos without permission. - Never send students to a general YouTube homepage when a specific chapter video can be linked. - Avoid unnecessary recommendation loops. NOTES Notes must be: - Short - Clear - Student-friendly - Chapter-specific - Structured for revision Recommended note structure: CHAPTER OVERVIEW KEY CONCEPTS IMPORTANT DEFINITIONS EXAMPLES FORMULAS / FACTS where applicable DIAGRAMS where applicable COMMON MISTAKES EXAM/TEST POINTS QUICK RECAP Do not copy entire textbooks into the site. Create original explanations and summaries where appropriate and respect copyright. QUESTION ANSWERS For every chapter provide: - Important NCERT-aligned questions - Short answer questions - Long answer questions where relevant - Conceptual questions - Application-based questions - Exam-style practice Clearly separate: QUESTION ANSWER KEY POINTS QUIZ Create an interactive chapter quiz. Requirements: - 5–10 questions - Multiple-choice - Clear correct/incorrect feedback - Score at the end - Retry button - Explanation after answering - Do not reveal answers before the student attempts - Track best score locally - Avoid repeated questions ONE SHOT Create a compact complete-chapter revision page. It should answer: “What do I need to remember if I only have 15–30 minutes?” RAPID REVISION Create an ultra-short revision sheet: - Key facts - Key definitions - Key formulas - Key concepts - Common mistakes - Important questions NCERT PRACTICE Provide: - Textbook-oriented exercises - Application questions - Practice sets - Self-check tasks Do not falsely claim that unofficial questions are exact NCERT questions. CLASS STRUCTURE Support: CLASS 6 CLASS 7 CLASS 8 CLASS 9 Use: Class → Subject/Curricular Area → NCERT Book → Chapter/Theme → Learning Resources Do not hard-code the site in a way that makes adding new books difficult.
